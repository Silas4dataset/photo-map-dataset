# Component terms

Only documentation is currently deposited. Data-component entries below describe
the intended scope, which must be finalized before data publication.

| Component | Applicable or intended terms |
|---|---|
| Independently authored repository documentation | CC BY-NC 4.0 under LICENSE.md |
| Future photographs | Intended CC BY-NC 4.0 for rights held by contributors, subject to privacy review |
| Future independently created region geometry, review decisions and method metadata | Intended CC BY-NC 4.0 only for independently grantable author-owned contributions; final scope pending |
| Future OSM maps, copied OSM entities, tags, footprints, names, centres and relevant annotation context | Retain applicable ODbL 1.0 requirements and attribution; no added NC restriction on OSM rights |
| Any database subject to ODbL share-alike obligations | Treat under the applicable ODbL obligations; do not replace these with CC BY-NC |
| Evaluation code, model predictions, weights and application | Not included |

For intended NC components, noncommercial sharing and adaptation require
attribution, a licence link and an indication of changes. Whether a use is
commercial depends on its purpose, not merely company or university status.
Commercial use is outside the NC grant where separate permission is required;
applicable legal exceptions remain unaffected.

A file can contain multiple origins. A folder-level author licence does not
override third-party fields or database rights. The eventual release will
identify these boundaries and retain the appropriate notices.
